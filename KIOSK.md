# Киоск на Windows

Как развернуть выставку на музейной машине: git + Node, сборка на месте,
локальный сервер, браузер в полноэкранном киоск-режиме. Docker не нужен.

## Что поставить один раз

1. **Node 22 LTS** — nodejs.org, обычный `.msi`, все галочки по умолчанию.
2. **Git for Windows** — git-scm.com (или просто скопировать папку проекта флешкой,
   тогда git не нужен, но обновлять придётся вручную).
3. **Chrome** — не обязателен, при его отсутствии запустится Edge.

## Развернуть

```
git clone <адрес репозитория> C:\yandexfestival
cd C:\yandexfestival
start.bat
```

`start.bat` при первом запуске сам поставит зависимости (`npm ci`, пара минут,
нужен интернет) и соберёт приложение (`npm run build`). Дальше поднимет сервер
и откроет браузер на весь экран. Последующие запуски — сразу шаг 3, несколько секунд.

Выйти из киоск-режима: `Alt+F4`. Сервер останется жить в свёрнутом окне
«YandexFestival server» — закрыть его отдельно.

## Доступ

- С самой машины: `http://localhost/`
- С других устройств в той же сети: `http://<IP машины>/` (узнать: `ipconfig`)

При первом запуске Windows спросит про фаервол — **разрешить для частной сети**,
иначе с других устройств не откроется. Если пропустили:

```
netsh advfirewall firewall add rule name="YandexFestival" dir=in action=allow protocol=TCP localport=80
```

Порт 80 занят (IIS, «Веб-публикации» и подобное)? Проверить `netstat -ano | findstr :80`,
затем поменять `set PORT=80` на `set PORT=8080` в начале `start.bat` — адрес станет
`http://localhost:8080/`.

## Автозапуск после перезагрузки

1. `Win+R` → `shell:startup` → откроется папка автозагрузки.
2. Перетащить туда `C:\yandexfestival\start.bat` **правой** кнопкой →
   «Создать ярлыки».

Всё. После входа в систему сервер и киоск поднимутся сами.

Питание: в «Параметры → Система → Питание» выставить «Экран — никогда»
и «Спящий режим — никогда», иначе экспозиция уснёт.

## Обновить версию

```
cd C:\yandexfestival
git pull
npm ci
npm run build
```

`npm ci` нужен, только если менялись зависимости; `npm run build` — обязательно,
иначе сервер продолжит отдавать старую сборку из `dist`. Затем перезапустить `start.bat`.

## Почему так, а не иначе

- **`npm run preview`, а не `npm run dev`.** Preview отдаёт готовую сборку из `dist`
  и сам разруливает SPA-маршруты (`/block/data/videos` и прочие открываются напрямую).
  Dev-сервер компилирует модули на каждый запрос и держит watcher — для витрины,
  работающей неделями, это лишнее.
- **Отдельный профиль Chrome** (`.kiosk-profile` рядом с проектом). Не трогает профиль
  сотрудника и сохраняет кэш роликов между запусками — второй запуск быстрее.
- **Интернет нужен только на `npm ci`.** После сборки всё содержимое, включая 103 МБ
  видео, лежит локально в `dist`, сеть не требуется.

Прод-деплой в облако — отдельная история, см. `DEPLOY.md`.
