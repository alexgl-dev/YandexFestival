# Деплой

## Прод

| | |
|---|---|
| URL | https://yandexfestival.promptsnight.ru |
| Сервер | ams-1 (`195.133.41.185`), Dokploy — панель на порту 3000 |
| Проект в Dokploy | `YandexFestival` → приложение `web` |
| Источник | этот репозиторий, ветка `main` |
| Сборка | `Dockerfile` в корне, контекст `.` |

Приложение полностью статическое: ни переменных окружения, ни базы, ни внешних
вызовов. Поэтому развёрнуто как Dokploy Application из Dockerfile, а не через
`docker-compose.dokploy.yml` — компоузу здесь нечего оркестрировать.

Домен работает через wildcard `*.promptsnight.ru` → `195.133.41.185`, поэтому при
смене поддомена DNS править не нужно. TLS — Let's Encrypt, выпускается сам.
Редирект HTTP → HTTPS делает Traefik Dokploy.

## Выкатить новую версию

Запушить в `main` и запустить деплой в панели Dokploy (или через API —
`application.deploy`, applicationId в creds-файле).

Важно: именно **deploy**, а не redeploy. `redeploy` пересобирает уже скачанный
чекаут и свежий коммит не подтянет.

## Что где

Реквизиты (ID проекта/приложения/домена, команды эксплуатации, предупреждения
по серверу) — `_00_SBER/Dokploy-services/yandexfestival-creds.md`, вне репозитория.

## Офлайн-режим для музея

**Windows-киоск — см. `KIOSK.md`**: клонировать репозиторий, запустить `start.bat`,
он поставит зависимости, соберёт проект, поднимет `vite preview` и откроет браузер
на весь экран. Docker на киоске не нужен, интернет — только на первый `npm ci`.

Если на машине уже есть Docker, тот же прод-образ запускается локально:

```bash
docker build -t yandexfestival .
docker run -d -p 8080:80 --restart unless-stopped yandexfestival
```

Дальше открыть `http://localhost:8080` в киоск-режиме браузера. Видео и картинки
лежат внутри образа, сеть после сборки не нужна.
